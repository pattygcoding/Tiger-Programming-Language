# Tiger Tutorial and Reference

Tiger combines dynamic values and first-class functions with explicit blocks, semicolons, and single-inheritance classes. This guide teaches the implemented language, not the full Python language or a planned feature set.

## Work Through an Example

Each `tg` code block is a complete program with its own fresh environment. Run it in the browser editor or place it in a file ending in `.tg`. The output immediately below it is the exact standard output, without command prompts. Examples labeled **Expected error** deliberately fail; their error block shows a diagnostic substring rather than a filename-dependent message.

After running a lesson's example, try the suggested variation. These exercises reuse features already introduced; they do not require unimplemented libraries.

## Verified Documentation

The documentation tests execute every `tg` block in this directory and the root README, compare displayed outputs, and check expected-error examples. They also check local Markdown link targets exist.

```sh
cargo test -p tiger-conformance --test documentation -- --nocapture
```

Run that command from the repository root. `cargo test` includes these checks too. Output examples are reference results, not regenerated by the test runner.

For larger programs, explore the [examples](../examples/demo.tg) and the [forty-three regression workloads](../benchmarks/README.md).
